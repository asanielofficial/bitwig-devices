# Template devices (not committed)

The builders copy small pieces (a dropdown, an image widget, a toggle and a boolean parameter, the audio in/out skeleton) from existing devices instead of writing them from scratch. Put these files here, downloaded from
[polarity/bitwig-devices](https://github.com/polarity/bitwig-devices) (`devices/`):

- `Orbit.bwdevice`
- `Rivet.bwdevice`
- `FILAR.bwdevice`
- `Normalizer.bwdevice`

Everything in this folder except this README is git-ignored. Check the license of those files before redistributing anything built from them.
